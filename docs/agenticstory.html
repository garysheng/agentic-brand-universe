The six bets

First principles

01
Universe-first
The evolving canon is primary. A work is a projection of it, and writes back into it.
02
Canon is medium-neutral
Entities carry no medium assumptions. Rendering is a pluggable layer. One renderer first.
03
References are load-bearing
Every asset resolves to a real file or the build fails loudly. A ref you can forget is a wish.
04
Quality = taste × craft × truth
Human gates, encoded craft-canon, and provenance — wired as steps, never left to memory.
05
Evolution is version control
Every canon change is a commit. Contradictions are diffs. Git is the evolution substrate.
06
Agent-writable by construction
Everything load-bearing is schema-checked data or prose in a known slot. Nothing hides in a head.

The stack

Five layers

Quality
taste gates · craft-canon · provenance — cross-cuts every layer
Renderer
projects canon + story into a medium — picture-book first, novels/scripts later
Story spec
a composition: selects canon + a beat sheet + a declared spine + provenance
Refs
the load-bearing resolver: entity → real asset, or crash — this layer kills silent drift
Canon
typed entities + relations, git-versioned — the living universe

Honest caveat: the framework was reverse-engineered from these books, so post-hoc expressibility is half-circular. Its real value isn't describing the last fifteen — it's stopping the recurring mechanical failures (scattered refs, drifting settings, the wrong-face leak, unsourced beats) and giving discovered taste a home so it's paid for once. Craft-canon grows by making stories; the system captures it, it doesn't pretend to precede it.
